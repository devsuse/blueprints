## Introduction

Blueprints is a collection of reusable components and utilities designed to help developers build applications faster and more efficiently.

## Get started

Blueprints is built on top of Shadcn, which provides a solid foundation for building modern web applications. To get started with Blueprints, run the following command to install the library:

```bash tab="bun::pm"
bunx shadcn@latest init devsuse/blueprints/base
```

```bash tab="npm::pm"
npx shadcn@latest init devsuse/blueprints/base
```

```bash tab="pnpm::pm"
pnpm dlx shadcn@latest init devsuse/blueprints/base
```

```bash tab="yarn::pm"
yarn dlx shadcn@latest init devsuse/blueprints/base
```

This command will initialize Shadcn for your project and set up the necessary variables and dependencies for Blueprints.

```bash tab="bun::pm"
bun dev
```

```bash tab="npm::pm"
npm run dev
```

```bash tab="pnpm::pm"
pnpm run dev
```

```bash tab="yarn::pm"
yarn run dev
```
